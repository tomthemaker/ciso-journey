# Today: daily study and recovery

Refs [S02 / #13](https://github.com/tomthemaker/ciso-journey/issues/13). Open the **Today** tab (`#today`, including under the Pages subpath). Original lessons, retrieval cards, questions and cases remain visibly AI-authored provisional drafts. Source metadata and agent task review do not establish educator/legal approval.

1. Open **Manage cards and daily new-card limit**. Explicitly enroll a single exact revision or the 12 foundation draft cards. Enrollment records no reading, answer, task completion or mastery. Choose 0–100 new introductions per local day; default five. A zero limit keeps all due/overdue reviews available.
2. Recall the prompt before choosing **Reveal answer**. The answer and four rating buttons enter the page only after reveal. Keyboard users can activate Reveal with Enter/Space, read the focused answer, then Tab to Again/Hard/Good/Easy. Again means failed recall; Hard means successful recall with effort. A saved rating advances to the next prompt with its answer hidden.
3. Use the original lesson, related question and optional executive case links. Return using Today. The next lesson follows the leading queued card's task; with no cards it uses the first unread current lesson. It offers an unattempted related question when possible, otherwise a retry, and the latest related optional case. These suggestions are simple deterministic navigation, not personalized competency recommendations. Lesson practice links elsewhere retain their exact versions.
4. Read the separate reading/resource/task/recall/question/applied assessment signals. Resource counts include archived completions; tasks count only the original 37 IDs; reading counts current lesson revisions. Saved case responses and their explicit rubric self-assessments are distinct. Six legacy 0–4 self-ratings remain in Competencies.

The rough plan adds one minute per currently available queued card, the supplied estimate for an unread selected lesson, and three minutes for one question. The optional case is a separate 15-minute assumption. It excludes retries, breaks and optional resources; it is neither a guarantee nor a mastery/readiness prediction. Actual FSRS due instants govern recall; current local timezone governs first-review daily caps. The model recall probability appears separately after reveal, absent before the first saved rating.

## Missed days and card management

Due/overdue reviews precede new cards; missing days does not reset them. First ratings alone consume the daily new-card cap. Newly due work/local-day rollover refreshes every 30 seconds when Today is visible without focused controls, or immediately using **Refresh due queue**, returning to the tab, or reloading. A revealed prompt remains available while you consider it. The estimate is a snapshot and can grow as reviews become due.

Suspend/archive excludes an exact revision without deleting schedules/events. **Restore** returns its original due date, including overdue work. An unknown/incompatible historical card stays in the backup and management list; its answer is never replaced with a current revision. Suspend/archive it if it blocks new-card selection, or restore a matching app/content bundle. Missing exact revisions are counted visibly among eligible work.

## Save failure and backups

Ratings use S01's `createReviewActions(Change)` and the existing IndexedDB transaction. A pending submission blocks other ratings. If persistence fails, the prompt stays revealed, committed history/schedule remain unchanged, and only **Retry [rating]** is available with the same event ID/time/rating. Restore storage availability or recover a conflicting tab before retrying. The draft is current-tab memory; reload discards an unsaved rating and hides the answer, leaving the durable due card available. A new successful rating never silently changes tasks, reading, resources, questions, case assessment or legacy scores.

Use **Export backup** regularly. Full v2 backups retain reading, resource progress, question attempts, review events/schedules/settings and case responses/self-assessments together with legacy data and compatible extensions. Import validates the whole candidate before confirmation/replacement. Existing v1 backups and original `ciso-journey-v1` recovery bytes remain compatible. For unavailable/quota/abort/corrupt/future storage, follow [F03 recovery](F03_STORAGE_AND_RECOVERY.md) and [S01's atomic/replay contract](S01_REVIEW_SCHEDULER.md). No real learner data belongs in the repository.
