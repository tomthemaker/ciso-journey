# R01 explainable personalized study

Issue: [#21](https://github.com/tomthemaker/ciso-journey/issues/21). Implementation: `src/study-plan.ts`, `src/study-preferences.ts`, `src/study-view.ts`. Candidate SHA and independent review belong in the PR; this document does not approve its own implementation.

The deterministic planner reserves roughly one minute per actual due review, including unavailable exact revisions, then selects one eligible activity that fits the remaining daily budget. Default budget is 45 minutes; the learner can save 1–480 minutes and any of the actual 37 task IDs as equal-priority goals. These are rough session assumptions, excluding retries and pauses. The planner never truncates the due queue, changes FSRS, enrolls cards, records completion or writes during rendering. Overdue work carries over unchanged. New-card limits and explicit enrollment retain their existing independent controls.

Automatic reading follows exact authored prerequisites, including historical revisions. Missing exact prerequisites and cycles produce visible warnings and block the affected automatic path; there is no fallback to an available newer revision. Goal task gaps use C01's provisional prerequisite graph and explicit task completion separately: reading does not complete a task. Multiple goals share prerequisites, with roadmap order and exact content key breaking remaining ties. A latest incorrect keyed MCQ or an explicit lowest available rubric self-rating supports a specific practice revisit. Unassessed text, unknown rubric anchors, successful flashcards, resource completion and legacy self-ratings do not establish applied competency or readiness. Quarterly appraisals remain separate self-reported records and are not inferred or required by this planner.

Today explains the selected activity, rough time, prerequisites, goal ties and budget overflow. Alternatives remain visible. Learners can deliberately select any available lesson/question/case revision, including over-budget or prerequisite-bypassing study; the persistent override shows warnings and remains until cleared. Historical/unavailable saved choices retain their exact reference and a recovery warning. Related study links and the full reading/task catalogs remain manual navigation.

`studyPreferences` is an optional schema-version-1 private namespace with a canonical UTC `updatedAt`, integer `dailyMinutes`, unique known `goalTaskIds` and optional exact `overrideRef`. Full-state validation rejects malformed settings before any write. F03 commits the deliberate settings change transactionally; failed saves retain the form draft and committed state. Both v1 imports and v2 full backups retain the namespace; absent settings preserve existing users. No recommendation render audit or growing decision history is stored. The authored 341-revision catalog, all 37 task IDs and six legacy self-ratings are unchanged.

Validation:

- `npm test`: fast unit checks, including deterministic cold start, conflicting goals, exact/historical/missing prerequisites, reading and task cycles, scarce time, explicit overrides, overdue load/unavailable cards, latest observed mistakes, explicit rubric feedback, invalid settings and both backup versions.
- `npm run typecheck` and `npm run build`.
- `npm run test:browser`: local desktop/mobile critical flows, including `tests/study-plan.spec.cjs` (settings, prerequisite override, reload, v1/v2 import/export, failed transaction and keyboard retry) and the existing review, preservation, Pages subpath and study flows. Browser installation/execution remains outside CI under D020.

Implementation model: `gpt-6.1-sol`, high effort, selected by the orchestrator for deterministic recommendation logic and private learner preference persistence. Independent exact-candidate Terra review is required before delivery; educator/legal content publication gates are unchanged.
